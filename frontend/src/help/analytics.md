# Web analytics

## What this does

Shows cached Search Console and GA4 traffic metrics. Use this page to select the
Search Console property when it is not deployment-pinned and to start a manual
traffic sync.

## Notes

- Owner reports read these cached snapshots.
- If an owner report shows pending traffic data, sync this page first, then
  regenerate the report.
