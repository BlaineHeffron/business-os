# Queue

## What this does

Queue is your work list — the items that need a person to review, approve, dismiss, or add context before the next step happens.

## How to operate it

- Select an item in the compact navigator. Its source, editor, and actions fill
  the larger detail pane; use j/k to process the list sequentially.
- Accept an item to approve it and start its drafts.
- Dismiss an item when nothing needs to happen.
- Dismiss only clears BusinessOS. For email items, Trash email also moves the source message to Gmail Trash after confirmation.
- Use + Log note to turn a call, walk-in, or reminder into a new item.
- Use + Create output to start a typed email or follow-up task without an
  inbound item. Choose manual mode to avoid an AI call, or add bounded context
  and an instruction for an AI proposal. You still review and approve it here.

## Common tasks

- Review a draft: accept the item, open Drafts, make any changes, then approve it.
- Rewrite an email: edit To, Cc, Subject, or Body, add an optional AI rewrite
  instruction, then review the rewritten body before approval.
- Save without approving: edit a staged email or follow-up task, then choose
  Save draft. If someone changed it elsewhere, Queue reloads the latest copy.
- Log offline work: choose + Log note, write what happened, and save it to the queue.
- Keep the list focused: stay on Needs you, and dismiss anything that no longer needs attention.
