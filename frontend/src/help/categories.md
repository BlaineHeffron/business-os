# Categories

## What this does

Categories are the buckets used to file mail and organize Queue work. Each one has a name, a definition of what belongs in it, and the outputs available for its work.

## How to operate it

- Keep names short and recognizable.
- Write a Definition that spells out what belongs in the category and what doesn't.
- Set Sort and color to make the list easy to scan.
- Turn on Work items for a category, then choose the outputs its items should create.
- Leave system categories in place unless you're deliberately changing the setup.

## Common tasks

- Add a category: choose + New category, enter a name and Definition, then choose Create category.
- Improve sorting: edit a category's Definition so future mail has clearer guidance, then Save changes.
- Change what items create: turn on Work items, expand the output settings, and toggle the outputs on or off — changes save as you toggle.
