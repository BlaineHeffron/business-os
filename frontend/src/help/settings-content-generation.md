# Content Generation Settings

## What this does

Content Generation Settings selects the document folder BusinessOS uses when drafting content. The selected folder should contain source documents, examples, and reference material that are safe for operators to use in customer-facing writing.

## How to operate it

- Connect Google before choosing a folder.
- Choose the folder that contains approved source documents.
- Choose Save after selecting or clearing the folder.
- Choose Sync now when you want BusinessOS to refresh the local document list.
- If the page says the folder changed elsewhere, review the reloaded value before saving again.

## Common tasks

- Change the source folder: select a different folder, choose Save, then Sync now.
- Pause document-backed drafting: clear the selected folder and choose Save.
- Fix missing access: reconnect Google, return to this page, then choose the folder again.
