# Settings

## What this does

Settings is where you configure this BusinessOS instance. The sections you see depend on what's enabled for the client — some clients see only one.

## How to operate it

- Pick a section from the list on the left to switch areas.
- Open the help button next to a section for details on it.
- Review the fields before saving.
- Choose Save inside a section to apply your changes.
- If a section says it changed elsewhere, review the reloaded values before saving again.

## Common tasks

- Find a setting: open Settings, choose the section, and review its fields.
- Change a setting: edit the fields and choose Save.
- See what's available: scan the section list — disabled areas aren't shown.
