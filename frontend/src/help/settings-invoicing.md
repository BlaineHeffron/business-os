# Invoicing Settings

## What this does

Invoicing settings set the default payment term used when an invoice draft arrives with no due date. It keeps due dates consistent before operators review and approve drafts.

## How to operate it

- Open Settings and choose Invoicing.
- Enter a whole number from 1 to 365 in Default payment term (days).
- Leave it blank to add no default due date.
- Choose Save to apply the setting.
- If the page says the setting changed elsewhere, review the reloaded value before saving again.

## Common tasks

- Set Net 30: enter 30 in Default payment term (days), then choose Save.
- Remove the default: clear the field and choose Save.
- Fix an invalid value: enter a whole number between 1 and 365, or leave the field blank.
