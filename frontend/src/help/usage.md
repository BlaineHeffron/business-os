# AI Usage

## What this does

AI Usage shows recent assisted-work activity — cost, timing, and errors. Use it to see how much AI help the client is using and whether anything failed.

## How to operate it

- Read Last 24 hours for recent calls, failures, tokens in and out, and cost.
- Read All time for the same totals across this instance's full history.
- Open Recent failures for the newest error details when calls fail.
- Scan the main table by when, purpose, route, correlation, model, in, out, latency, and outcome.
- Choose Debug for a failed call when debug access is enabled.

## Common tasks

- Check today's activity: read Last 24 hours, then scan the main table for recent outcomes.
- Investigate a failure: open Recent failures, read the purpose and error, then choose Debug when available.
- Review cost: compare Last 24 hours and All time before changing model settings.
