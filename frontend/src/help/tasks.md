# Tasks

## What this does

Tasks tracks follow-up work to finish later — reminders and due-dated items that shouldn't get lost in the Queue.

## How to operate it

- Switch between Open, Done, and All to see current, finished, or every task.
- Work the Overdue and Due today lanes first.
- Mark a task Done when it's finished.
- Reopen a task if it needs more attention.
- Refresh to pull the latest list right away.

## Common tasks

- Clear today's work: open Tasks, work the Overdue and Due today lanes, and mark each one Done.
- Look ahead: stay on the Open filter and scan the Upcoming lane for anything to prepare.
- Reopen finished work: switch to Done or All, find the task, and choose Reopen.
