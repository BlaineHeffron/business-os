# Inbox

## What this does

Inbox shows incoming messages that BusinessOS has sorted for review. Use it to see what arrived, why each message landed where it did, and whether it needs a rule, a new category, or follow-up.

## How to operate it

- Open a message to read the sender, subject, labels, and body excerpt.
- Press j and k to move through the list, Enter to open, Esc to close.
- Create a rule from a sender or domain so similar mail sorts the same way next time.
- Add a follow-up when a message needs work you'll come back to.
- Choose Trash to dismiss any matching Queue item and move the source message to Gmail Trash. It stays recoverable there until Trash is emptied.

## Common tasks

- Turn repeated mail into a rule: open a typical message, choose + Rule from this sender (or sender domain), confirm the match, and save.
- See why a message landed where it did: open it and check the sender, labels, and matching rule against its category.
- Keep the inbox moving: clear the newest mail first, and turn repeating patterns into rules instead of fixing them one by one.
