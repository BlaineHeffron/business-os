# Content campaign studio

## What this does

Use Content to plan keyword-targeted topics and open one end-to-end workspace per campaign. The workflow keeps research evidence, the editable blog article, compact social variants, exact-revision approval, and delivery status together.

## Common tasks

- Add a topic with its target keyword, audience, angle, and format.
- Select the topic and choose Generate campaign. BusinessOS searches the approved research library and web evidence before drafting the cited article.
- Edit and approve the evidence-checked article, enter the expected canonical HTTPS URL, then generate and edit per-channel social variants.
- Select the exact blog/social destinations, then explicitly publish now or schedule.
- Watch the blog delivery complete first. Social posts are created only after the publishing connection returns the expected canonical URL.
- Refresh the published list from local analytics and published plans.
- Add older published pages manually when they were not created from a plan.

## Notes

Overlap warnings are advisory. Live publishing remains off until an administrator enables each connection. A dry-run blog result never creates social posts. If the publishing connection returns a materially different canonical URL, BusinessOS stops social publishing and marks the campaign for review rather than posting a surprising link.
