# AI Settings

## What this does

AI Settings controls which models BusinessOS uses for different kinds of assisted work. Use it to connect a Claude.ai subscription, set the default model, give a specific job a stronger model, or apply a temporary override while testing.

## How to operate it

- If Claude subscription mode says **Needs sign-in**, choose **Connect subscription** and finish the Claude sign-in page.
- Paste the one-time authorization code back into BusinessOS. The code is passed directly to Claude Code and is not stored.
- Use **Refresh sign-in** whenever Claude reports that the subscription session needs authorization again.
- Check the Default model before changing individual rows.
- Turn on an override only for a job that needs a different model.
- Choose Save once the model name looks right.
- If the page says the settings changed elsewhere, review the reloaded values before saving again.

## Common tasks

- Connect or refresh Claude: choose **Connect subscription** or **Refresh sign-in**, finish authorization, then paste the one-time code.
- Change the default model: set Default model, then choose Save.
- Override one job: tick its row, pick the model, then choose Save.
- Remove an override: untick the row and Save so it returns to the default.
