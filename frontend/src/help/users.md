# Users

## What this does

Users manages operator accounts and their sign-in tokens. Use it to add people, replace tokens, disable access, and set your own default calendar when one's available.

## How to operate it

- Enter a display name and choose Add user to create an operator.
- Copy the token the moment it appears — it's shown only once.
- Choose Rotate token to issue a replacement for an existing operator.
- Choose Disable to stop a token from working, or Enable to restore access.
- On your own row, pick a default calendar when the picker is shown.

## Common tasks

- Add an operator: enter their display name, choose Add user, copy the token, and share it through a secure channel.
- Replace a lost token: choose Rotate token, copy the new one, and have the operator sign in with it.
- Remove access: choose Disable and confirm — the token stops working immediately.
