# Rules

## What this does

Rules tell BusinessOS how to sort repeated mail. Use them when a sender, subject, label, or other pattern should always land in the same category.

## How to operate it

- Choose + New rule for mail that follows a clear pattern.
- Put specific rules above broad ones — the first match wins.
- Preview a rule against recent inbox mail before relying on it.
- Disable a rule to pause it without deleting it.
- Choose Re-run rules to apply the current rules to existing mail.
- Choose Re-check AI triage to clear stale AI verdicts so the background re-check can look again. It does not re-run rules.

## Common tasks

- Route a repeated sender: choose + New rule, match the sender, pick the category, preview it, then save.
- Tune a broad rule: choose Edit, add another condition, preview the result, then save.
- Re-check AI triage after changing categories or AI policy if old fallback mail needs a fresh AI pass.
- Clean up old sorting: disable or delete rules that no longer match how the business works.
