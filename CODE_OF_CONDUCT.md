# Code of Conduct

## Expected conduct

Treat each participant with respect.

Use clear technical language.

Accept review of ideas and code.

Give useful feedback about the work.

Respect privacy and do not publish personal or client information.

## Unacceptable conduct

Do not harass, threaten, insult, or discriminate against another participant.

Do not publish private information without permission.

Do not disrupt project work or project spaces.

## Enforcement

Report a conduct problem privately to the project maintainers.

The maintainers can edit or remove content that violates this policy.

The maintainers can limit or remove participation after a violation.
